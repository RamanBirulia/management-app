# Release 5.2.1 — Project Color Coding

- Статус: **завершён**
- Родительский этап: Release 5.2 — Context Export

## Цель

Сделать принадлежность Work Items к проектам заметной при быстром просмотре общего дерева и backlog, не смешивая этот сигнал с зелёным цветом людей/команд и синим цветом inline project mentions.

## Реализация

- У проекта появилось сохраняемое поле `color`.
- Используется ограниченная палитра: amber, coral, purple, rose, graphite и brown; зелёный и синий намеренно исключены.
- Цвет выбирается при создании и редактировании проекта.
- В справочнике цвет виден на project avatar.
- В Planning первая принадлежность задаёт цвет левой границы Work Item; каждый связанный проект дополнительно получает собственный компактный цветной chip.
- Существующие проекты автоматически распределяются по палитре во время миграции.

## Ограничения

Цвет — вспомогательный сигнал: slug остаётся видимым, поэтому интерфейс не полагается только на различение цветов. Для Work Item с несколькими проектами граница использует первый проект, а chips показывают все связи.
