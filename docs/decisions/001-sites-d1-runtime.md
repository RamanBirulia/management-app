# ADR-001: D1 для опубликованной Sites-версии

- Статус: принято
- Этап: Stage 1

## Контекст

Product Vision рекомендует PostgreSQL для production-like развёртывания на выделенной машине. Одновременно текущая пользовательская версия публикуется через Sites, где raw TCP-подключения к PostgreSQL недоступны. Stage 1 требует серверного хранения, которое переживает перезагрузки и доступно с разных устройств.

## Решение

Использовать Cloudflare D1/SQLite как серверную базу опубликованной Sites-версии. Существующий PostgreSQL, Docker Compose и Caddy контур сохраняется как отдельный production-like вариант. Доменная модель и API проектируются так, чтобы не привязывать UI к конкретному SQL runtime.

## Последствия

- Опубликованный Stage 1 получает настоящую серверную сохранность без browser storage.
- Schema хранится в `db/schema.ts`, а migrations — в `drizzle/`.
- Персональные Markdown-notes хранятся как обычный текст в D1; рендеринг выполняется безопасным React-компонентом без raw HTML.
- Для будущего переноса на PostgreSQL потребуется отдельная совместимая миграция и реализация data access, но UUID, статусы и API-контракт сохраняются.
- До появления реальных чувствительных данных необходимо отдельно решить аутентификацию и политику доступа.
